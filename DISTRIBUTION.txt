- OBS 연결 시 실제 감지 화면 표시. 연결이 끊기면 이전 영상 대신 상태 표시.
- 시작 전: 미리보기, 기록·소리 없음.

- 필수 창·입력값 오류 표시. 설정이 부족하면 시작 버튼 회색 처리.

- 실제 소리 재생 시 [현재 시간] (ᓀ‸ᓂ) 표시. 음소거 중에는 표시 없음.

- Language 라벨은 영어 고정. 미리보기·활동 로그는 선택 언어로 표시.

모드
- 위치 추적: 기본 모드. X/Y 좌표·이동량 기록, 선택 가능한 이동량 경고.
- 원형 판정: 고정 원 기준 이탈 경고·채점. 경계는 원 안으로 판정.
- 원형 비프음 OFF: 소리만 끔. 이탈 표시·채점·경고 기록 유지.
- 모드와 연결 창은 시작 전에 선택. 모니터링 중 임계값 변경 가능.
- X·Y 개별: |ΔX| ≥ X 또는 |ΔY| ≥ Y
- 합산 거리: sqrt(ΔX² + ΔY²) ≥ 거리 기준
- 기준은 원본 OBS 캡처 픽셀 단위. 오른쪽 +X, 아래쪽 +Y.
- 경고 ON: 기준 이상 이동 시 붉은 표시와 비프음. 델타 비프음은 최대 초당 1회.
- Position: 첫 정상 감지 기준 좌표. Delta: 직전 정상 감지와 현재 감지의 차이.
- A → 미감지 → B는 B-A 비교. 미감지 뒤의 값도 임계값 이상이면 경고.
- 첫 감지는 비교 대상 없음. 미감지 CSV 좌표·이동량은 공란.

측정 가이드
- 이동량 경고 우측 토글. 비프음과 별도로 ON/OFF 가능.
- 실제 감지 영역에 X/Y는 사각형, 합산 거리는 원으로 표시.
- 직전 정상 좌표 기준. 첫 감지 전에는 감지 영역 중앙 기준.
- 실제 원본 픽셀 비율로 표시. 감지·채점·기록에는 영향 없음.
- 원형 판정에는 별도 측정 가이드 없음. 샘플 영상에서도 실제 원형 판정 표시.

샘플 영상
- 하단 ▶ 아이콘 또는 S: 14초 영상 반복 재생 / 중지 후 실제 화면으로 전환.
- 기존 OBS 반복 영상의 검은 감지 영역 사용: 1920×1080, 30fps, 소리 없음.
- 좌표·이동량·원형 판정·측정 가이드를 같은 화면에서 확인 가능.
- 샘플은 미리보기 전용. 기록·비프음 없음. 모니터링 시작 시 실제 OBS로 전환.
- 반복 시작 시 좌표 기준 초기화. 영상 끝에서 처음으로 이동한 값은 비교 제외.
- --sample 옵션으로 실행하면 샘플 영상 재생 상태로 시작.

기록과 단축키
- R: CSV 기록 시작/종료, M: 음소거, ESC: 모니터링 종료
- C: 게임 타이머 영역 이미지 저장, D: 다시 감지
- F5 / Ctrl+R: 시작 전 창 목록 새로고침
- 실제 화면 하단 아이콘으로 실행 및 상태 확인. 마우스를 올리면 기능·단축키 표시.
- 비프음 설정 OFF일 때 M 버튼 비활성. 설정을 켜면 일시 음소거 사용 가능.
- 텍스트 입력 중에는 단축키 작동 안 함.
- 종료 시 진행 중인 기록 저장. 기록 폴더: EXE 옆 azusa_record
- 설정 파일: EXE 옆 config.json
- 자동 기록 기본: 시작 타이머 55–59초 연속 감지 후 60초 기록·저장.
- 기록 > 시간 지정: 1–3600초 설정. 모니터링 시작 전에 변경.
- 중간 타이머·캡처 미감지나 0–1초 감지는 시간 지정 기록을 조기 종료하지 않음.
- 실시간 남은 시간 표시. 자동 종료 후에도 모니터링 유지, 5초 대기 후 다음 시작 감지.
- 기존 방식은 기록 > 타이머 감지 선택: 0–1초 감지 또는 2초 넘는 미감지 시 종료.
- R·ESC·다시 감지·창 종료·자동 기록 OFF·캡처 크기 변경은 조기 종료 가능.
- 기존 config.json에 종료 방식이 없으면 시간 지정·60초 기본 적용.
- 좌표 기록은 CSV. 영상 녹화 기능 아님.
- 내장 숫자 템플릿으로 타이머 인식. Tesseract OCR은 EXE에 미포함.
